# 🛍️ UrbanCart | Premium E-Commerce Experience

## 🎯 Why KeyTech Global Built This Website

**UrbanCart** is a modern, conversion-optimized e-commerce storefront developed by KeyTech Global to demonstrate our capability in building enterprise-grade online shopping platforms.

This project showcases:

- Advanced e-commerce functionality  
- Clean, intuitive UI/UX design  
- Performance-focused architecture  
- Real-world retail use case implementation  

We built UrbanCart to prove that a fully functional e-commerce platform — including cart management, filtering systems, and dynamic UI interactions — can be developed using **pure HTML, CSS, and Vanilla JavaScript** without external frameworks.

## 🛠️ Technologies & Tools Used

- 📄 **HTML5** — Semantic structure for accessibility & SEO  
- 🎨 **CSS3** — Flexbox, Grid, animations, responsive design  
- ⚙️ **Vanilla JavaScript** — Core e-commerce functionality  
- 💾 **LocalStorage API** — Persistent cart storage  
- 🖼️ Unsplash API — High-quality product imagery  
- 🔄 CSS Transforms & Transitions — Interactive animations  
- 📱 Mobile-First Approach — Fully responsive layout  
- 🔧 Event Delegation — Optimized event handling  
- 🎯 Intersection Observer — Scroll animations & lazy loading
